# Scramble generator attribution

BTime uses the `randomScrambleForEvent` function from [cubing.js](https://github.com/cubing/cubing.js) to generate random-state puzzle scrambles. Version 0.59.1 is distributed locally under `assets/vendor/` for offline use.

The cubing.js project is licensed under the [Mozilla Public License 2.0 (MPL-2.0)](https://github.com/cubing/cubing.js/blob/main/LICENSE-MPL.md). The license text is included in `cubing-LICENSE-MPL.md`. BTime uses precompiled esm.sh modules, with module/worker paths rewritten to local files and unavailable source-map links removed; library behavior is unchanged. Original source URLs are recorded in `assets/vendor/inventory.json`. Keep the module sources, upstream notices, and license texts when redistributing.
