# Scramble generator attribution

BTime uses the `randomScrambleForEvent` function from [cubing.js](https://github.com/cubing/cubing.js) to generate random-state puzzle scrambles. The library is loaded from the [cubing.net CDN](https://cdn.cubing.net/v0/js/cubing/scramble).
